# Five-minute demo — use only verified features

Before judges arrive: run doctor, API, web, evaluation and per-session workers; verify keys/credits, phone battery, HTTPS, venue network and audio. Keep a real previous consented test interview as a clearly labeled backup. Do not create fake scored sessions for visual fullness.

0:00–0:40: Create role and upload actual consented sample resume. Review extracted text, show default 10 and exact recruiter-defined question. Generate and approve relevant questions.

0:40–1:20: Candidate consents and checks media. Scan one-use phone QR, grant separate consent. Show primary continuing while secondary joins; show separate server receipt if implemented and verified.

1:20–2:35: Answer a real project question. Demonstrate bounded contextual follow-up only if completed. Use repeat and confirmed skip. Explain explicit Done as a control, not a fully autonomous semantic model if that gate remains unfinished.

2:35–3:35: Have a consented teammate enter secondary frame for the calibrated duration. Show actual timestamped snapshots. Contrast ordinary movement without labeling it cheating. If no reliable detector fires, disclose the missed event instead of injecting one manually.

3:35–4:45: Open a previously completed actual session, labeled as previous. Show transcripts, citations, rubric outputs, coverage gaps, evidence and reviewer override. Play real recording only when finalized and verified.

4:45–5:00: “Verity organizes interview evidence. The recruiter makes the decision.” State measured results and known limits, not estimated superiority.

Fallback hierarchy: real live media -> honestly labeled existing consented recording -> text interaction with missing-media notice. Never substitute prerecorded video as live without disclosure.
